      About Target Curve Builder

      Target Curve Builder is a free tool for building, importing and editing the target curves that Smaart uses in its transfer function view. Make a house curve for a PA or sound system, then export it as a Smaart .crv file in one click. It runs entirely in your browser: nothing is uploaded, there is no account, and it works offline once loaded.

      How it works

      1. Start from a preset (a 3 dB/oct tilt with a 32 Hz high-pass, the cinema X-curve, A or C weighting) or from a flat curve, or import an existing .crv.
      2. Add layers: low-frequency, full and high-frequency tilts, Butterworth, Linkwitz-Riley, Bessel or Chebyshev high-pass and low-pass filters up to 96 dB/oct, shelves, bells, shapes and your own points. They add together, and you can drag points on the graph.
      3. Choose the output grid (1/1 to 1/48 octave, the imported points, or breakpoints only), then export the .crv. In Smaart, import it from the target curve manager.

      Questions

      What is a Smaart target curve?

      A .crv file of frequencies and levels that Smaart draws behind a transfer function trace, so you can tune a system towards it. Transfer function target curves need a measurement-capable edition of Smaart 9.4 or later, or Smaart Data Modeler.

      Can I use it for REW or other software?

      Yes. It can also export plain text (Hz and dB) and a Smaart ASCII trace, and import a measurement as a reference trace.

      Is it free to use?

      Yes, for any non-commercial purpose, under the PolyForm Noncommercial licence. The source is on GitHub.

      Import

      You already have a curve open. What should the file do?

      Replace opens the file as the curve, with its own name, colour and header. Add as a layer keeps your curve and adds the file's points as a new Points layer that sums with the other layers. Both can be undone.

      Open a shared curve?

      This link holds a curve. Opening it replaces the curve you have open now. You can undo that.
