      ASCII export writes Smaart's trace text layout: Hz, dB, phase and coherence, tab-separated, values rounded to 2 decimals. A target curve has no phase or coherence, so those columns are 0.00 and 1.00.

      TF target curves need a measurement-capable edition of Smaart 9.4 or later, or Smaart Data Modeler. Smaart RTA can't import them.
